# Scene 0.2.0

One theme for your whole Mac: the wallpaper, Light/Dark, window borders, terminals, code editors, and command-line tools change together, and Scene can put your original setup back.

- 76 themes, with three backgrounds for every look. New: Aetheria, with red-to-lime window borders.
- Themes for Ghostty, iTerm2, kitty, Alacritty, Warp, Terminal, VS Code, Cursor, VSCodium, Windsurf, Zed, Xcode, Neovim, Helix, tmux, bat and delta, btop, herdr, and JankyBorders.
- The Theme Maker: make your own theme with sliders and a live preview.
- Neovim keeps Scene's theme when a plugin sets another one at startup.
- Xcode gets Scene's theme back after it quits, when it saved its default over it.
- Scene checks for updates. Turn it off in Settings, under Updates.
