# Scene 0.3.0

- Your own scripts. Add them in Settings → Scripts, and Scene runs them after each theme with its colors in `SCENE_` variables and in `~/.config/scene/theme.json`. After Restore they run again with `SCENE_EVENT=restore`.
- Set as Wallpaper. Use any theme's background without its colors, from the button on its page or a background's menu. Your theme stays the current one.
- The wallpaper on every Space, not only the one on screen (experimental, tested on macOS 27.2). Restore brings back each Space's own wallpaper.
- kitty: Scene sets every color a kitty theme sets, so your old theme's titlebar no longer shows through.
- A command that hangs no longer holds up an apply. Scene stops it after its time limit.
