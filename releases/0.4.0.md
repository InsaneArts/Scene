# Scene 0.4.0

- New apps: Rio, bateri, and the Herdr app among the terminals, Doom Emacs among the editors, and lazygit, k9s, and ZapFast among the tools.
- Flexoki has a dark look.
- Following Light/Dark no longer fails on the wallpaper when System Settings sends a second switch.
- Rex gets the theme when Rex is open on more than one Mac.
- Scene finds Neovim, Helix, and other tools installed with mise, and themes Neovim whenever its config folder exists.
- ZapFast shows a new theme without a restart once it uses Scene's palette.
