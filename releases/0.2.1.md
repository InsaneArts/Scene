# Scene 0.2.1

- Install a shared theme from the command line: `Scene --install-theme github.com/owner/repo`. It takes the same Scene and Omarchy theme repositories as Add Theme → Install from GitHub.
- The theme skill for AI agents uses it, so you can ask your agent to install a theme someone shared.
- The menu bar panel shows every theme when Scene starts at login without its window. Before, it could stay empty.
