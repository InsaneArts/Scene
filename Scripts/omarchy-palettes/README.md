# Omarchy palettes

`colors.toml` from each built-in theme of [Omarchy](https://github.com/omacom/omarchy) at tag v4.0.4
(commit c668141e), unchanged. Omarchy is MIT licensed: https://github.com/omacom/omarchy/blob/v4.0.4/LICENSE

`Scripts/make-bundled-themes.py` reads these files. Only the colors are used; Omarchy's config files and Lua are not copied.
